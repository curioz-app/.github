# Curioz

**Le quiz de culture générale quotidien.** Chaque matin, tous les joueurs reçoivent le même défi de 10 questions (histoire, sciences, géographie, art, sport, langue française…), avec l'explication de chaque réponse. On compare ses scores entre amis, en famille ou entre collègues.

Gratuit, sans publicité, sur iOS, Android et dans le navigateur.

- Site : [curioz.app](https://curioz.app)
- 100 questions de culture générale avec réponses : [curioz.app/quiz/culture-generale](https://curioz.app/quiz/culture-generale)
- Le quiz du jour : [curioz.app/quiz-du-jour](https://curioz.app/quiz-du-jour)
